## 你的任务

1. 从上游调研里选 **2-3 篇最具代表性的论文**（一篇奠基、一篇 SOTA、一篇与你的想法最接近）。
2. 对每篇依次使用 `paper_read`（拿章节结构与关键段落）与 `paper_note`（生成结构化笔记）。
   若本地没有 PDF，先用 `paper_fetch` 下载。
3. 用 `paper_compare` 生成对比矩阵（问题设定 / 核心方法 / 数据集 / 指标 / 局限）。
4. 回答三个关键问题：
   - 它们的**共同假设**是什么？这个假设在什么情况下会失效？
   - 哪一步是真正的「瓶颈」而不是表面指标？
   - 如果只能改一个地方，改哪里最可能带来论文级贡献？
5. 用 `write_file` 把精读结论写入 `reading-notes.md`。

## 产出要求

最终回答包含：
- 每篇论文：一句话总结 / 方法拆解 / 实验证据 / 批判点
- 对比矩阵 Markdown 表
- 「共同假设 + 瓶颈 + 可下手处」三段式结论
- 2-3 个可迁移到本课题的设计

质量红线：区分「论文声称」与「实验证明」；对可疑实验设置（无参数量匹配、单 seed、数据泄漏）明确点出。
