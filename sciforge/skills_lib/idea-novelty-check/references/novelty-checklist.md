## 2. 撞车风险分级

| 等级 | 定义 | 应对 |
|---|---|---|
| P0 | 同机制 + 同设定 + 同指标 | 正面撞车：找差异/换方向/做对比实验 |
| P1 | 同机制 + 不同设定 | 强调设定差异，补跨设定对比 |
| P2 | 不同机制 + 同目标 | 可共存：引用 + 讨论互补性 |
| P3 | 弱相关 | 一句话 Related Work 即可 |

## 3. 差异化定位句式

- 「与 X 不同，我们**不需要** <额外假设/数据/训练阶段>。」
- 「X 关注 <A 场景>，我们针对 <B 约束>，因此 <C 能力> 是必要的。」
- 「我们在**相同预算**下比 X 高 <x>，且首次给出 <分析/数据集/协议>。」
