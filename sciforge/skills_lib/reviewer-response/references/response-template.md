# Rebuttal 模板与话术

## 1. 回复信骨架

```text
We thank all reviewers for their constructive feedback. Below we address each
comment in order. Major changes are highlighted in blue in the revised manuscript.

# Reviewer 1
## R1-W1: <审稿意见要点>
**Response.** <结论句：我们做了什么/为什么>.
<证据：实验编号、数字、引用>.
**Revision.** Sec. 3.2, Table 2, Fig. 4.

# Reviewer 2
...
```

## 2. 按意见类型的回应策略

| 类型 | 首句 | 证据要求 |
|---|---|---|
| 补实验要求 | "We agree this is important and added the requested experiment." | 新 Table/Figure + 数字 + 设置说明 |
| 方法质疑 | "We appreciate this point. The key difference is ..." | 对比表格/公式/引用 |
| 误解 | "We apologize for the unclear presentation; we have clarified that ..." | 修改前后文字对照 |
| novelty 质疑 | "Our key distinction from <work> is ..." | 并排对比 + 具体差异 |
| 要求引用 | "We thank the reviewer for pointing us to <paper>; we now discuss it in ..." | 引用位置（相关才引） |
| 写作问题 | "We revised Sec. X for clarity." | 修改位置 |
| 无法补充 | "Due to <constraint>, we could not run X; instead we provide <evidence>, and we have added this limitation in Sec. Y." | 替代证据 + 诚实声明 |

## 3. 补实验优先级

1. 审稿人共同要求（≥2 人）——必做；
2. 直接攻击核心 claim 的实验——必做；
3. 强 baseline 对比——尽量做；
4. 其他数据集/规模扩展——时间允许再做；
5. 写作类——零成本，先改。

## 4. 礼貌且有据的话术

- 避免：「The reviewer is wrong.」「This is already clear in the paper.」
- 使用：「We appreciate the reviewer's perspective.」「To make this clearer, we ...」
- 每段先给结论，再给证据；数字具体化，不用 "significantly" 代替 p 值/差值。
- 承认局限：「We acknowledge this limitation and discuss it in Sec. 5.2.」

## 5. 一致性清单

- [ ] 回复中的编号（Table/Figure/Section）与修改稿一致。
- [ ] 承诺的修改确实在 PDF 中，且在修改稿中标出。
- [ ] 所有审稿人问题都被编号覆盖。
- [ ] 回复字数/页数符合会议的 rebuttal 限制。
- [ ] 不贬低审稿人，不引用未经核实的文献。
