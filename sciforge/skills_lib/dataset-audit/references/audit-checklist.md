# 数据审计指标与 datasheet

## 1. 核心指标

| 维度 | 指标 | 采样方式 |
|---|---|---|
| 规模 | 样本数/标注数/split 比例 | 全量统计 |
| 完整性 | 缺失率、损坏率、空样本率 | 全量或分层抽样 |
| 分布 | 类别分布、长度分位、分辨率分布 | 全量统计 + 直方图 |
| 不平衡 | 最大/最小类比例、长尾覆盖 | 类别计数 |
| 重复 | 精确重复率、近重复率、跨 split 重复 | hash + MinHash |
| 标签质量 | 抽样错误率、多标注一致性 kappa | 100-500 条人工核验 |
| 泄漏 | 与测试集/预训练集重叠率 | n-gram / embedding / hash |
| 许可 | 许可证类型、可再分发性、敏感内容 | 文本核对 |

## 4. Datasheet 模板（发布数据集用）

1. **动机**：为什么创建、解决什么问题、谁维护。
2. **组成**：样本类型、数量、语言、采集时间、标注流程。
3. **采集**：来源、爬取策略、是否含用户数据、脱敏方式。
4. **预处理/清洗**：规则与版本。
5. **用途**：预期任务、禁止用途。
6. **分布**：类别/领域/地域/时间分布。
7. **维护**：更新频率、反馈渠道、许可证。
8. **伦理**：个人信息、偏见、潜在危害与缓解。
9. **引用**：BibTeX 与 DOI。

## 5. 风险清单模板

- [ ] 标签噪声率 X%，可能影响指标 ±Y。
- [ ] 长尾类别 Z 个样本数 <100，per-class 指标方差大。
- [ ] 数据来源集中在 A 领域，跨域泛化未经测试。
- [ ] 许可证限制再分发，仅发布下载脚本。
- [ ] 与预训练语料重叠未知（若无法检查，在 limitation 说明）。
