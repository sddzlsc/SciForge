# 研究方向生成（Research Ideation）

## 何时使用（触发条件）

- 刚进入一个新方向，需要从「模糊兴趣」走到「具体可做的问题」。
- 现有项目卡住，需要换视角、找相邻领域的可迁移方法。
- 头脑风暴/组会前，需要结构化地产生一批想法再筛选。

## 输入 / 输出

- 输入：兴趣领域、已有资源（数据/算力/代码）、时间预算、目标 venue 偏好。
- 输出：`ideation.md`：10-20 个一句话想法（按透镜分类）、Top 3 展开（问题/假设/最小实验/风险）、筛选记录。

## 工作流

1. **明确约束**：时间（3 个月/1 年）、算力（单卡/8 卡）、数据可得性、必须与已有工作差异化的方向。
2. **多透镜生成**（每透镜至少 2 个想法，先求量）：
   - 问题优先：找真实瓶颈/失败案例；
   - 抽象阶梯：上移（更一般）或下移（更具体）；
   - 跨域迁移：把 A 领域成熟机制搬到 B；
   - 约束反转：去掉假设（无标注/低算力/在线/隐私）；
   - 尺度变换：更小/更大/更长/更多模态；
   - 评测盲区：现有 benchmark 没测什么；
   - 组合创新：两个弱 gap 组合成强故事。
3. **快速证伪**：每个想法问三句——「谁需要？」「为什么现在没人做/为什么难？」「最小实验能否证伪？」；把明显不可行的划掉。
4. **Top 3 展开**：写问题陈述、核心假设、最小实验（1 GPU ≤2 天）、预期贡献、撞车风险。
5. **novelty 快查**：Top 3 各做一轮 `lit_search`（近 12 个月），撞车则调整约束。
6. **交接**：交给 `innovation-mining` 做 gap 矩阵细化，或直接进 `experiment-design`。

## 质量检查清单

- [ ] 至少覆盖 5 种透镜、每种 2 个想法，避免单一思维模式。
- [ ] 每个想法能一句话说清「做什么、为什么值得做」。
- [ ] Top 3 有可证伪假设和最小验证实验。
- [ ] 已考虑算力/数据/时间约束，不是空想。
- [ ] novel 快查完成，撞车风险有判断。
- [ ] 明确写出「放弃哪些、为什么放弃」。

## 失败处理

| 情况 | 处理 |
|---|---|
| 想不出想法 | 回到失败案例/limitation/新硬件三条线；或做「约束反转」练习 |
| 想法都很平庸 | 组合两个不同透镜（如跨域 + 评测盲区）；提高约束强度（10× 更低成本） |
| 想法太大做不完 | 下移抽象阶梯：限定一个场景/数据集/指标 |
| 想法太小没贡献 | 上移：抽象成通用机制，或补理论/评测贡献 |
| 与已有工作重复 | 换约束轴（预算/模态/场景/可解释性）；或做扎实的复现+分析 |
| 团队意见分散 | 用 3 维评分（新颖/影响/可行）投票，保留前 2 个并行 pilot |

## SciForge 工具与 CLI 对应

| 步骤 | 工具 / CLI |
|---|---|
| 文献背景 | `lit_search`、`literature-survey` skill |
| 撞车快查 | `idea-novelty-check` skill |
| 生成/打磨 | `sciforge idea --topic "..."`、`sciforge chat` |
| 后续细化 | `innovation-mining` skill |
| 立项后 | `autoresearch-loop` skill |

## 示例

```bash
sciforge idea --topic "高效长上下文视频生成" --from-library
# 再用三透镜补：约束反转（无检索）、跨域迁移（音频 memory）、评测盲区（>2min 一致性）
sciforge lit search "long video generation memory efficiency" --since 2025
```
