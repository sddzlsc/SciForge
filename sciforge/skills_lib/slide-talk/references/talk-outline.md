# Talk 逐页模板与 Q&A 题库

## 1. 12 分钟会议 talk（12-14 页）

| # | 页面 | 时长 | 要点 |
|---|---|---|---|
| 1 | 标题 + 作者 | 15s | 一句话介绍自己 |
| 2 | 问题与动机 | 60s | 为什么重要、具体场景 |
| 3 | 现有方法局限 | 60s | 2-3 个失败模式（配图） |
| 4 | 核心洞察 | 45s | 我们的关键观察（一句话） |
| 5 | 方法总览（Figure 1） | 90s | 数据流 + 模块 |
| 6-7 | 关键机制 | 120s | 公式/伪代码 + 直觉 |
| 8 | 实验设置 | 30s | 数据/指标/baseline |
| 9-10 | 主结果 | 120s | 主表 + 一句解读 + 趋势 |
| 11 | 消融 | 60s | 每个模块的必要性 |
| 12 | 结论与展望 | 45s | takeaway + 未来工作 |
| backup | 超参/效率/失败案例/相关工作 | - | 备用 |

## 2. Poster 结构（A0 竖版）

- 左上：标题/作者/单位/二维码；右上：一句话 takeaway。
- 左列：问题 → 动机 → 贡献列表。
- 中列：方法总览图 + 关键公式 + 流程。
- 右列：主结果表/图、消融、结论。
- 底部：代码/数据二维码、致谢。
- 字号：标题 ≥72pt，正文 ≥24pt，图注 ≥18pt。

## 3. Q&A 题库

**方法类**
- 为什么选择这个模块而不是 X？去掉它会怎样？
- 与 <concurrent work> 的核心区别？
- 训练/推理成本？能否在单卡跑？

**实验类**
- baseline 是否调过参？是否同预算？
- 为什么只在 2 个数据集上验证？
- 方差多大？显著吗？

**理论/边界**
- 假设在什么情况下不成立？
- 失败案例长什么样？

**应用/影响**
- 能用到什么真实场景？数据隐私？
- 负面社会影响？

回答原则：先给结论句，再给证据（数字/图/编号），不确定就承认并给验证计划。

## 4. 排练检查

- [ ] 计时完整走 2 遍，控制在时长 90% 以内。
- [ ] 每页过渡句写下来。
- [ ] 讲稿口语化，避免念稿。
- [ ] 关键数字（1-3 个）能脱口而出。
- [ ] backup slides 按问题分类排好（方法/实验/理论/应用）。
