API 端点
打开 /api/docs

            

              

                
方法路径说明

                
                  
GET/api/health版本 / LLM / 工具 / 服务器 / 模块就绪度

                  
GET/api/tools已注册工具及 tags、JSON Schema

                  
POST/api/chatSSE：meta / llm_delta / assistant / tool_call / tool_result / stage / error / done

                  
GET/api/library本地文献库（未就绪时 available=false）

                  
GET/api/literature/search真实检索优先，否则回退 demo fixtures

                  
GET/api/servers服务器配置（脱敏，不含任何密钥）

                  
GET/api/gpunvidia-smi 归一化表格（可选 ?server=）

                  
GET/api/paper/read论文精读（PDF → 章节结构，T1 工具）

                  
GET/api/recipes内置 pipeline recipe 列表

                  
GET/api/runspipeline 运行历史（读 run.json）

                  
POST/api/pipeline/run后台线程启动 pipeline，返回 run_id

                  
GET/api/pipeline/{run_id}轮询状态 / 阶段 / 事件 / 产物

                  
GET/api/skillsSkill 列表（SkillManager 优先，否则只读扫描）

                  
POST/api/skills/install-dsh安装技能到 ~/.dsh/skills

                  
GET/api/artifacts项目产物 / demo fixtures 清单

                  
GET/figures/{path}项目内图片（防目录穿越）

                  
GET/files/{path}项目内任意产物文件（防目录穿越）

                
              

            

          

          

            

              
安全边界

              
    
                
  • 仅监听回环地址 127.0.0.1，默认 8765 端口
    • 
                
  • /files、/figures resolve 后校验必须位于项目根内，拒绝 .. 与绝对路径
    • 
                
  • 服务器输出剔除密码、密钥与环境变量值；identity_file 仅展示路径
    • 
                
  • LLM API key 只从环境变量 / ~/.sciforge/config.toml 读取，不写入项目目录、不回传浏览器
    • 
                
  • 响应带 CSP / nosniff / Referrer-Policy 头；无第三方 CDN 请求
    •
